# Утренняя сводка по рынку → Telegram

Скрипт раз в сутки собирает цены (BTC, ETH, курс ЦБ, иена, Nasdaq),
сверяет их с 14 триггерами плана и присылает сводку в Telegram.
Отдельными сообщениями приходят сигналы: 🔴 сработал порог, 🟡 подошли ближе 1%.

Сейчас он работает на Маке через launchd. Проблема: если компьютер спит
или не в сети в 09:45 — сводки нет. На Railway этой проблемы не будет.

---

## Как развернуть на Railway (15 минут, один раз)

### 1. Установить Railway CLI

Открыть Терминал и выполнить:

    npm install -g @railway/cli

Проверить, что установилось:

    railway --version

### 2. Войти в аккаунт

    railway login

Откроется браузер — авторизоваться через GitHub или почту.

### 3. Создать проект и залить код

    cd /Users/artem/Documents/market-signals-railway
    railway init

Ввести название проекта, например `market-signals`. Затем:

    railway up

Код уедет на Railway. Первая сборка — 1–2 минуты.

### 4. Прописать секреты

В браузере открыть проект на railway.com → вкладка **Variables** →
добавить три переменные:

| Переменная | Значение |
|---|---|
| `TG_TOKEN` | токен бота из BotFather |
| `TG_CHAT_ID` | `150462912` |
| `STATE_PATH` | `/data/state.json` |

Токен бота лежит в старом скрипте: `/Users/artem/Scripts/market-signals/digest.py`, первые строки.

### 5. Подключить диск для памяти

Настройки сервиса → **Volumes** → **New Volume** → путь монтирования `/data`.

Диск нужен, чтобы скрипт помнил вчерашние статусы триггеров. Без него
сигналы будут приходить заново каждый день, даже если ничего не изменилось.

### 6. Поставить расписание

Настройки сервиса → **Cron Schedule** → вписать:

    45 6 * * *

Это 06:45 UTC = **09:45 по Москве**. Railway живёт по UTC, поэтому 6, а не 9.

Важно: при включённом расписании Railway запускает контейнер, тот
отрабатывает и выключается. Платите только за минуту работы в сутки.

### 7. Проверить

Настройки → **Deployments** → у последнего деплоя **View Logs**.
Должно быть: `OK: сводка отправлена`. И сообщение придёт в Telegram.

Можно запустить вручную кнопкой **Redeploy**, не дожидаясь утра.

## После того как заработает

Выключить старую задачу на Маке, чтобы сводка не приходила дважды:

    launchctl unload ~/Library/LaunchAgents/com.artem.market-signals.plist

Если что-то пойдёт не так, вернуть обратно:

    launchctl load ~/Library/LaunchAgents/com.artem.market-signals.plist

---

## Что менять потом

**Пороги триггеров** — в `digest.py`, список `trigs` в функции `main()`.
После правки: `railway up` — и новая версия уедет.

**Время отправки** — Cron Schedule в настройках сервиса. Помните про UTC.

## Сколько стоит

Railway берёт около $5 в месяц за аккаунт (Hobby). Скрипт работает
несколько секунд в сутки, так что расход в этот минимум укладывается.

## Что проверить после первого запуска

Скрипт ходит на `cbr.ru` за курсом ЦБ. Сайт российский, Railway — зарубежный.
Если в логах будет ошибка именно на курсе доллара, значит ЦБ не отдаёт данные
с зарубежного адреса — тогда заменим источник на биржевой курс.
